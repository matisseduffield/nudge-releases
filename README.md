# Nudge releases

Signed Android builds of Nudge: to-do lists with reminders that ring.
Free, no ads.
Installed copies update themselves from here.

**[Download Nudge 1.2.9](https://raw.githubusercontent.com/matisseduffield/nudge-releases/main/Nudge.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 1.2.9

- With large text, the date and time fields sit one above the other so AM/PM and the year stay visible
